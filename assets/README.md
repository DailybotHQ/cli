# Brand assets

Both logos are the official Dailybot horizontal wordmark, downloaded from
[dailybot.com/images/brand](https://www.dailybot.com/images/brand/logo-horizontal-white.svg),
as SVG with a **transparent background**.

| File | Use |
|---|---|
| `logo-dark.svg` | White ink — dark backgrounds. The README serves this one on GitHub's dark theme. Source: `logo-horizontal-white.svg`. |
| `logo-light.svg` | Black ink — light backgrounds. The README serves this one on GitHub's light theme, and as the fallback for renderers without theme switching. Source: `logo-horizontal-black.svg`. |
